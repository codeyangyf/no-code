## Task 8: 项目CRUD与生命周期

> 设计文档 Task 8：项目CRUD与生命周期（INITIALIZING/READY/FAILED/ARCHIVED/PENDING_DELETE）

**目标：** 实现项目的完整CRUD操作，管理项目生命周期状态。

**Files:**
- Create: `backend/project-core/src/main/java/com/lc/project/dto/ProjectDTO.java`
- Create: `backend/project-core/src/main/java/com/lc/project/service/ProjectService.java`
- Create: `backend/project-core/src/main/java/com/lc/project/service/impl/ProjectServiceImpl.java`
- Create: `backend/project-core/src/main/java/com/lc/project/controller/ProjectController.java`
- Modify: `backend/project-core/pom.xml`（添加必要依赖）

**项目状态枚举：**
| 状态 | 说明 |
|------|------|
| INITIALIZING | 初始化中（创建项目数据库） |
| READY | 就绪（可正常使用） |
| FAILED | 创建失败 |
| ARCHIVED | 已归档（停用但保留数据） |
| PENDING_DELETE | 待删除（等待清理资源） |

**接口设计：**
- `GET /api/projects` - 项目列表（分页）
- `GET /api/projects/{id}` - 项目详情
- `POST /api/projects` - 创建项目
- `PUT /api/projects/{id}` - 更新项目
- `DELETE /api/projects/{id}` - 删除项目
- `PUT /api/projects/{id}/status` - 切换状态

**关键设计：**
1. 创建项目时触发异步任务创建数据库
2. 删除项目时级联删除项目数据库
3. 项目状态流转需符合状态机约束

**Task 8-1: 创建 ProjectDTO + ProjectService 接口**
**Task 8-2: 创建 ProjectServiceImpl 实现**
**Task 8-3: 创建 ProjectController 控制器**
**Task 8-4: 编译验证 + Commit**

## Global Constraints（继承自 Phase 1）

- Java: 17
- Spring Boot: 3.2.5
- 多租户约束：租户内唯一字段使用 (tenant_id, code) 复合唯一
